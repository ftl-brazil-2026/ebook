## Leituras Recomendadas

Semanalmente, iremos recomendando leituras para ajudar a digerir o amplo e complexo sistema de dados geoespaciais.

- Pebesma, E.; Bivand, R. (2023). [Spatial Data Science: With Applications in R](https://r-spatial.org/book/). Chapman and Hall/CRC.
- Bivand, R. S.; Pebesma, E.; Gómez-Rubio, V. (2013). *Applied Spatial Data Analysis with R*, 2nd ed. Springer.
- QGIS Documentation 3.40. <https://docs.qgis.org/>
