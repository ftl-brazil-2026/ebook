## Pattern for adding material to a week

- **Narrative page** — add a `.md` or `.qmd` file in this folder, then list it under this week's `contents:` in `_quarto.yml`.
- **Hands-on notebook** — drop a `.ipynb` file in this folder and list it the same way; it renders as a page and stays downloadable as-is.
- **Slides** — create a `.qmd` file with `format: revealjs` in its front matter (see Quarto's [revealjs docs](https://quarto.org/docs/presentations/revealjs/)) and list it too.
:::
